# tetris-bqswlg



這是一個使用 C 語言編寫的 Windows 終端機版俄羅斯方塊 (Tetris) 遊戲。本專案透過終端機輸出與 ANSI 控制碼，在命令列介面中實作了完整的俄羅斯方塊遊玩體驗。

## 遊戲特色

* **終端機彩色介面**：利用 ANSI 色彩碼為 7 種不同形狀的方塊提供專屬顏色。


* **預覽功能**：在遊戲區右側會顯示接下來即將出現的 3 個方塊 (Next Queue)。


* **完整的方塊控制**：支援左右移動、旋轉、加速下落以及瞬間落下 (Hard drop)。


* **消行機制**：當方塊填滿一整列時會自動消除並獲得分數。



## 環境與相依性限制

* **作業系統**：Windows (程式碼依賴 `<windows.h>` 中的 `GetAsyncKeyState` 與 `Sleep` 函數)。


* **編譯器**：支援 C 語言的編譯器 (例如 GCC / MinGW)。


* **終端機**：需支援 ANSI 逃逸序列 (ANSI escape codes) 的終端機 (建議使用 Windows Terminal 獲得最佳顯示效果)。



## 操作說明

遊戲透過鍵盤進行操作，預設的按鍵對應如下：

* **向上鍵 (`↑`)**：旋轉方塊


* **向左鍵 (`←`)**：將方塊向左移動


* **向右鍵 (`→`)**：將方塊向右移動


* **向下鍵 (`↓`)**：加速方塊下落


* **空白鍵 (`Space`)**：瞬間將方塊落下至底部



## 編譯與執行方法

1. 將原始碼檔案 `tetr.c` 儲存至您的本機目錄。


2. 開啟終端機或命令提示字元，並切換至該檔案所在的資料夾。
3. 使用您的 C 編譯器進行編譯（以 gcc 為例）：
```bash
gcc tetr.c -o tetris

```


4. 執行編譯後的程式開始遊戲：
```bash
.\tetris.exe

```
